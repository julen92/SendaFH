# Créditos de SendaFH

## Proyecto original

SendaFH es una adaptación de **[Polestar](https://github.com/fitzforge/polestar)**,
creado por **[Fitz / fitzforge](https://github.com/fitzforge)** y sus colaboradores.
El motor del addon, sus guías y sus herramientas parten de ese proyecto.

La beta preparada `SendaFH 0.5.0-test.1` utiliza como base `Polestar v0.2.5-test.1`,
commit `5445b96713ad1176da173721edd7aa927b29bf1a`.

**Forever Hispano** mantiene la adaptación de SendaFH: traducción, estilo visual,
comandos y soporte para su comunidad. El nombre SendaFH identifica nuestra adaptación;
no implica que el equipo original publique o avale esta versión.

## Navegación

Polestar integra trabajo de **Cillian Berragan / [cjber](https://github.com/cjber)**,
autor de **[Shortest Path Forever](https://github.com/cjber/shortest-path-forever)**.
Se conserva su licencia, copyright y atribución, así como los créditos de los mapas
de navegación de Polestar y de los datos de cruces de zonas de Carbonite.
