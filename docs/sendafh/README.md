# Recursos de la portada

- portada.svg: recurso vectorial propio de Forever Hispano.
- guia.png y opciones.png: vistas previas de la interfaz Lua de SendaFH 0.5.0-beta.1, generadas fuera del juego con datos de ejemplo localizados.

Las vistas previas usan las herramientas de renderizado y la interfaz derivadas de Polestar, con sus créditos y licencias originales. No son capturas del cliente de WoW.

- forever-hispano-logo.png: logo utilizado por el Discord de Forever Hispano, incorporado a la portada a petición de la comunidad. Los elementos de World of Warcraft conservan sus marcas y derechos originales.
- portada.png: versión renderizada de portada.svg para mostrar el logo integrado en GitHub.
