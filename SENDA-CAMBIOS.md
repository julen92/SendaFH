# SendaFH 0.5.0-beta.1

First CurseForge publication of the Forever Hispano adaptation of Polestar.

- Includes the full Polestar v0.2.5-test.1 addon base and its 220 guides.
- Adds the Spanish guide catalogue and esES/esMX interface and name packs.
- Integrates the 122 esES improvements contributed to and merged into Polestar in PR #139.
- Includes the Hispano appearance, `/senda` commands and Forever Hispano support links.
- Updates version and website metadata for this distribution.
- Includes editable translation catalogues, guide sources and build tools under `SendaFH/Source/`.
- Keeps the eight addon directories at the ZIP root. Optional Windows migration scripts are kept in the separate source archive, outside the CurseForge installer.

## Validation

38 translation, name and complete-module loading checks passed; 42 Spanish text-layout checks passed. Both Spanish locales cover 1606/1606 interface strings with no format errors. All 220 guides load with no missing catalogue entries, and the navigation data integrity check passes. Full in-game route validation is still pending.
